# Security

Repository: https://github.com/baditaflorin/newsletter-flow

## Supported Versions

The latest tagged release and `main` branch receive security fixes.

## Reporting

Please report vulnerabilities privately through GitHub Security Advisories:

https://github.com/baditaflorin/newsletter-flow/security/advisories/new

Disclosure email:

baditaflorin@users.noreply.github.com

## Scope

Newsletter Flow is a static GitHub Pages app. It has no hosted backend, no server-side database, and no bundled secrets. Drafts and sources are stored locally in the user's browser.

Never submit real API keys, private keys, tokens, passwords, or private drafts in public issues.
